# Governance

@pix-galaxy/pix-color-scheme-selector is maintained by the pix-galaxy suite stewards.

## Maintainers

Current maintainers:

- Emiliano Pisu (@pixu1980) - creator and lead maintainer

## Decision Making

Day-to-day decisions are made by the maintainers. Significant API changes, new public exports, breaking changes or architectural shifts are discussed in issues or pull requests before implementation.

## Contribution Model

External contributions are welcome following the process in CONTRIBUTING.md. All contributions are reviewed by maintainers before merging.

## Sub-teams

There are no sub-teams at this time. If the project grows, sub-teams may be formed for specific areas (themes, lexers, tooling).

## Conflict Resolution

If maintainers disagree on a decision, the discussion is documented in the relevant issue or pull request. If consensus cannot be reached, the lead maintainer makes a final decision and explains the reasoning publicly.

## Changes to Governance

Changes to this document require a pull request approved by the lead maintainer.
