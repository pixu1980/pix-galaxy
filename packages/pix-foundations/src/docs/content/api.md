# API

## Tokens

All tokens are CSS custom properties on `:root`, prefixed with `--pix--`.

| Group | Prefix | Example |
|-------|--------|---------|
| Radii | `--pix--r--` | `--pix--r--md: 8px` |
| Spacing | `--pix--s--` | `--pix--s--md: 1rem` |
| Colors | `--pix--c--` | `--pix--c--text: oklch(…)` |
| Elevations | `--pix--e--` | `--pix--e--md: 0 4px 12px …` |
| Focus | `--pix--f--` | `--pix--f--width: 2px` |
| Typography | `--pix--t--` | `--pix--t--font-family: system-ui` |
