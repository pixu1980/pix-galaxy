# Examples

## All formats visible

The picker shows HEX, RGB, HSL, and OKLCH values simultaneously.

```html
<pix-color value="#e11d48"></pix-color>
```

## With form

```html
<form>
  <pix-color name="accent" value="#22c55e"></pix-color>
</form>
```

## Contrast checking

The footer shows WCAG AA/AAA pass/fail against white and black backgrounds.
